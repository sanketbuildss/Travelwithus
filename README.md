# RAJASTHAN — A Royal Journey

A responsive, cinematic Rajasthan travel website concept with an interactive Three.js miniature fort, GSAP scroll animations, destination filters, mobile navigation and a demo itinerary builder.

## Files
- `index.html` — page structure and content
- `style.css` — responsive visual system, typography, layout and motion
- `script.js` — interactions, GSAP effects, Three.js scene and trip planner

## Run it on Android
1. Download and extract the ZIP.
2. Open the extracted folder in Acode or another code editor.
3. Open `index.html` using the editor's preview / local web server.
4. Internet is needed for Google Fonts, Unsplash images and CDN libraries (GSAP, Lucide and Three.js).

## Features
- Responsive layouts for phones, tablets, laptops and wide desktop screens
- Playfair Display + DM Sans + Outfit typography
- Deep navy, warm gold and sandstone colour palette
- Real-time 3D fort scene constructed in Three.js (drag to rotate, pause/resume auto-rotation)
- Destination filters, animated reveal effects, mobile menu, demo itinerary planner
- Reduced-motion support and graceful fallback if WebGL/CDN is unavailable

## Important notes
- This is a front-end concept, not a booking engine. It does not submit reservations or store user data.
- Photos are remote Unsplash image URLs. Image availability, attribution and license suitability should be verified before commercial use; replace with locally licensed assets if needed.
- CDN libraries and web fonts require internet access. If a CDN is blocked, the page will fall back to mostly static functionality.
- The 3D fort is a stylized procedural model built from geometry, not a photogrammetry scan of a real monument.
- Some text statistics are explicitly marked illustrative; verify facts and official visitor information before publishing.
