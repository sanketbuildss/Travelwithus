# Rajasthan — The Royal Route (Level 2)

A cinematic, responsive Rajasthan travel website built with HTML, CSS and JavaScript. Includes GSAP/ScrollTrigger enhancements, mobile navigation, theme toggle, destination filters/search, hover interactions, and a demo itinerary form.

## Run on Android
1. Download and extract the ZIP.
2. Open `index.html` in Acode or another code editor with browser preview.
3. Keep internet on for Google Fonts, GSAP CDN and remote Unsplash photos.
4. If you publish it, upload the files to GitHub Pages, Netlify, or another static host.

## Files
- `index.html` — page content
- `styles.css` — design and responsive styling
- `script.js` — interactions and animations
- `assets/design-reference.png` — visual concept reference (if included)

## Notes
- GSAP is loaded from CDN. If it doesn't load, basic scroll-reveal effects fall back to IntersectionObserver.
- The trip planner is a front-end demo. It does not book trips or send data anywhere.
- Photo URLs are external. Replace them with licensed images for commercial use.
- This version does not use a full 3D model yet; the cinematic parallax is implemented as a lightweight mobile-friendly effect. A real interactive 3D fort can be added as a later asset-heavy upgrade.
